# grantex_webhook (Resource)

Manages a Grantex webhook. Webhooks deliver real-time event notifications to your application via HTTP POST requests, signed with HMAC-SHA256.

The Grantex API has no update endpoint for webhooks, so changing `url` or `events` replaces the webhook (and rotates its secret). The signing secret is generated by the API and returned once, at creation.

## Example Usage

```hcl
resource "grantex_webhook" "grant_events" {
  url    = "https://example.com/webhooks/grantex"
  events = ["grant.created", "grant.revoked", "token.issued"]
}

output "webhook_secret" {
  value     = grantex_webhook.grant_events.secret
  sensitive = true
}
```

## Schema

### Required

- `url` (String) - The URL to deliver webhook events to. Changing this forces a new resource.
- `events` (List of String) - The list of event types to subscribe to. Valid values: `"grant.created"`, `"grant.revoked"`, `"token.issued"`. Changing this forces a new resource.

### Read-Only

- `id` (String) - The unique identifier for the webhook.
- `secret` (String, Sensitive) - The server-generated secret used to sign webhook payloads for HMAC-SHA256 verification. Available only for webhooks created by Terraform; it cannot be recovered after creation.
- `created_at` (String) - The timestamp when the webhook was created.

## Import

Webhooks can be imported using the webhook ID:

```shell
terraform import grantex_webhook.grant_events <webhook_id>
```

The `secret` of an imported webhook is unknown to the API and stays `null`.
