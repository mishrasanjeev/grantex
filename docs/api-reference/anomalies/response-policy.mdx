---
openapi: get /v1/irregularities/response-policy
description: Read the Grantex account irregularity response policy when IRREGULARITY_RESPONSE_POLICY_ENABLED is enabled; otherwise the endpoint returns 404.
---

Use `PATCH /v1/irregularities/response-policy` with `{"mode":"alert_only"}` or
`{"mode":"revoke_agent_grants"}` to change this account-wide setting. It affects
the legacy detector only. The server rollout flag is off by default.
