## Endpoint

```
GET /v1/dpdp/breaches
```

## Authentication

Requires a developer API key in the `Authorization` header.

## Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `status` | `string` | No | `open`, `initial_intimated`, `reported` or `closed` |
| `limit` | `integer` | No | 1 to 200, default 50 |
| `cursor` | `string` | No | The `nextCursor` of the previous page |

## Example Request

```bash
curl "https://api.grantex.dev/v1/dpdp/breaches?status=open&limit=20" \
  -H "Authorization: Bearer gx_..."
```

## Response -- 200 OK

```json
{
  "breaches": [
    {
      "breachId": "brch_01HXYZ...",
      "status": "open",
      "awareAt": "2027-06-01T10:00:00.000Z",
      "affectedCount": 3,
      "boardDetailedReportDueAt": "2027-06-04T10:00:00.000Z",
      "boardDetailedReportOverdue": false,
      "principalIntimationRequired": true
    }
  ],
  "nextCursor": null
}
```

Each item has the fields [Record Breach](/api-reference/dpdp/record-breach)
returns (shortened above), without `affectedDataPrincipalIds`,
`principalIntimation` and `principalIntimations`; read one breach for those.

## Error Responses

| Status | Code | Description |
|---|---|---|
| 400 | `BAD_REQUEST` | Unknown `status`, invalid `limit` or `cursor` |
| 401 | `UNAUTHORIZED` | Invalid or missing API key |
