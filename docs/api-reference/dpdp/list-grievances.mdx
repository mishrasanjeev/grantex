---

## Endpoint

```
GET /v1/dpdp/grievances
```

## Authentication

Requires a developer API key in the `Authorization` header.

## Query Parameters

| Parameter | Type | Required | Description |
|---|---|---|---|
| `status` | `string` | No | `submitted`, `in_review`, `resolved` or `rejected` |
| `dataPrincipalId` | `string` | No | Only this data principal's grievances |
| `limit` | `integer` | No | Page size, 1 to 200 (default 50) |
| `cursor` | `string` | No | The `nextCursor` of the previous page |

## Example Request

```bash
curl "https://api.grantex.dev/v1/dpdp/grievances?status=submitted" \
  -H "Authorization: Bearer gx_..."
```

## Response -- 200 OK

```json
{
  "grievances": [
    {
      "grievanceId": "grv_01HXYZ...",
      "dataPrincipalId": "user_abc123",
      "recordId": null,
      "type": "consent-violation",
      "status": "submitted",
      "referenceNumber": "GRV-2026-01J9Z6ZC4Q8F2V1K3M5N7P9R0S",
      "expectedResolutionBy": "2026-04-12T14:00:00.000Z",
      "responsePeriodDays": 7,
      "resolvedAt": null,
      "resolution": null,
      "createdAt": "2026-04-05T14:00:00.000Z",
      "updatedAt": null
    }
  ],
  "nextCursor": null
}
```

List entries leave out `description` and `evidence`; read them with
[Get Grievance](/api-reference/dpdp/get-grievance).

## Error Responses

| Status | Code | Description |
|---|---|---|
| 400 | `BAD_REQUEST` | Unknown `status`, `limit` outside 1 to 200, or an invalid `cursor` |
| 401 | `UNAUTHORIZED` | Invalid or missing API key |
