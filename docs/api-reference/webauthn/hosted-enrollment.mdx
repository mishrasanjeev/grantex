---
openapi: get /passkey-enroll
description: Open Grantex hosted passkey enrollment with a one-use ticket in the URL fragment. This browser page requires the enrollment rollout flag.
---

The browser page uses `POST /v1/webauthn/enroll/options` and
`POST /v1/webauthn/enroll/verify` to register one passkey with a valid ticket.
The ticket is supplied in the URL fragment and removed from browser history.
