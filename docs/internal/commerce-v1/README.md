# Historical Commerce V1 Internal Records

This folder is historical/internal context. C6, C6W, C6X, and C6Y files document earlier preview, compatibility, cache, audit, review, and retention slices. Every C6W, C6X and C6Y report is historical and carries a note saying so; the C6K, C6L and C6M preview records and the open-protocol packaging draft are historical too, because those preview routes were removed.

The C6W4-C6W9 and C6X2 library helpers these records describe were never mounted on a route and have been deleted from the code, together with the C6X3-C6Y5 compatibility tests built on them. The records stay as history only; see [OACP library helper decision](../../guides/oacp/library-helper-decision.mdx).

The historical documents are not launch approval, not public protocol publication, not external certification, and not evidence that Grantex owns merchant connector runtime or every buyer/seller interaction. Grantex's current role is OACP trust, policy, artifact authority, verification, and adapter governance.
