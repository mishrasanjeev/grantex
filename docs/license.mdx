## Summary

Grantex has two licences.

| Part | Licence | Commercial use |
|---|---|---|
| SDKs and client packages in `packages/` (TypeScript, Python and Go SDKs, framework integrations, verifiers, MCP, x402 and MPP packages, CLI, Terraform provider and the rest) and the examples | [Apache License 2.0](https://github.com/mishrasanjeev/grantex/blob/main/packages/sdk-ts/LICENSE), open source | Free for any use, including commercial |
| The Grantex server and developer portal (`apps/`), the protocol specification text, this documentation and the website | [PolyForm Noncommercial License 1.0.0](https://github.com/mishrasanjeev/grantex/blob/main/LICENSE), source-available, from **21 October 2026** including all updates | Needs a written agreement with Orchestrum Technologies LLP |

The licensor for both is Orchestrum Technologies LLP.
[LICENSING.md](https://github.com/mishrasanjeev/grantex/blob/main/LICENSING.md)
lists the directories exactly.

## Server, portal and hosted services

| Use | Needs an agreement? |
|---|---|
| Self use for noncommercial purposes: personal study, research, experiments, testing, hobby projects | No |
| Other noncommercial uses the licence names, such as use by charitable, educational, public research and government organisations | No |
| Running the auth service or portal inside a for-profit business, including pilots and proofs of concept | Yes |
| Hosting, SaaS or a managed service offered to others | Yes |
| Resale, bundling or commercial redistribution of the server or portal | Yes |
| Consulting, integration or other paid services that run or deploy the server | Yes |
| Commercial use of the hosted services (`grantex.dev` APIs) | Yes |

Only self use is free. Commercial use of any sort needs Orchestrum's prior
approval and a written agreement with Orchestrum Technologies LLP. Write to
[sanjeev@orchestrum.in](mailto:sanjeev@orchestrum.in), or see
[commercial licensing](/compliance/licensing) for what to include and how an
agreement is put in place.

## SDKs and client packages

The SDKs and client packages stay open source under the Apache License 2.0.
You can use them in commercial products, run them in production and
redistribute them, keeping their licence and notices. Calling the hosted
services commercially is a separate matter covered above.

## Existing users and earlier releases

Releases of the server, portal and other PolyForm-licensed parts published
before 21 October 2026 remain available under the Apache License 2.0 they were
released with. Versions, updates, fixes and security patches of those parts
published from that date are covered by the PolyForm Noncommercial License
1.0.0, so using them commercially needs an agreement, whether or not you used
an earlier release before.

## What the PolyForm licence requires when you share

If you pass on a copy of a PolyForm-licensed part for a permitted purpose,
include the licence terms (or their URL) and the `Required Notice:` lines at the
top of the [LICENSE](https://github.com/mishrasanjeev/grantex/blob/main/LICENSE)
file.
