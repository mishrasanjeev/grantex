## Summary

Grantex has two licences.

| Part | Licence | Use by an organisation |
|---|---|---|
| SDKs and client packages in `packages/` (TypeScript, Python and Go SDKs, framework integrations, verifiers, MCP, x402 and MPP packages, CLI, Terraform provider and the rest) and the examples | [Apache License 2.0](https://github.com/mishrasanjeev/grantex/blob/main/packages/sdk-ts/LICENSE), open source | Free for any use, including commercial |
| The Grantex platform: the server and developer portal (`apps/`), the protocol specification text, this documentation and the website | [Orchestrum Personal Use License 1.0](https://github.com/mishrasanjeev/grantex/blob/main/LICENSE), source-available, from **21 October 2026** including all updates | Needs prior written permission from Orchestrum Technologies LLP in a signed agreement |

The licensor for both is Orchestrum Technologies LLP.
[LICENSING.md](https://github.com/mishrasanjeev/grantex/blob/main/LICENSING.md)
lists the directories exactly.

Only an individual using the platform for their own personal purposes is free.
Every organisation needs prior written permission from Orchestrum Technologies
LLP in a signed agreement, whether the use is paid or free. There is no
exception for evaluation, charities, education, research or government. Write
to [sanjeev@orchestrum.in](mailto:sanjeev@orchestrum.in), or see
[commercial licensing](/compliance/licensing) for what to include and how an
agreement is put in place.

## SDKs and client packages

The SDKs and client packages stay open source under the Apache License 2.0.
You can use them in commercial products, run them in production and
redistribute them, keeping their licence and notices. Calling the hosted
services commercially is a separate matter covered above.

## Existing users and earlier releases

Releases published before 21 October 2026 remain available under the terms
they were released with. Versions, updates, fixes and security patches of the
platform published from that date are covered by the Orchestrum Personal Use
License 1.0, so an organisation needs written permission to use them, whether
or not it used an earlier release before.
